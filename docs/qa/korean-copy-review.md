# 한국어 문구 전수 검토 · 2026-09-08

## 검토 범위

공개 도구 121개와 비공개 후보 6개의 소개, 사용 범위, 제작 가능성 설명, 기능 목록, 어려운 기능, 운영 안내, 자주 묻는 질문, 제작 프롬프트를 읽고 다듬었다. 홈·검색·상세·분야별 목록·가입·로그인·프로필·커뮤니티·제안·관리자·통계·오류 안내·이메일 문구와 공유 이미지도 확인했다.

가격 수치, 결제 방식, 출처 주소·확인일, 공개 여부, 대체 판정 코드는 기존 데이터와 대조해 변경되지 않았음을 확인했다. 제작 프롬프트는 기존 기능 범위에 맞게 작업 흐름과 표현을 고친 버전 1.0.1이다. 이 검토가 127개 도구를 실제로 제작했다는 뜻은 아니다.

## 표현 기준

- 화면 안내는 짧고 구체적인 존댓말을 쓴다. 버튼은 사용자가 할 행동을 적는다.
- 명사 여러 개를 “흐름을 설계”로 뭉뚱그리지 않고, 실제 작업 순서와 목적을 설명한다.
- 구현한 기능과 구현하기 어려운 부분을 구분하고, 실제 제작 검증 여부를 명확히 알린다.
- 제품명, 코드, 파일 형식과 개발에 필요한 기술 용어는 정확성을 유지한다.
- 사용자 게시글·댓글과 실제 제작에 사용한 원본 요청문은 교정 대상에서 제외한다.

## 검증

E18 시나리오는 121개 상세 페이지를 너비 360px로 열어 한글 제목, 대체 가능성 표시와 가로 넘침 여부를 확인한다. 게시글의 긴 제목·잘못된 게시판·잘못된 자료형에 대한 한국어 오류, 도구 제안의 한글 선택 항목, 관리자·내 활동·통계·글쓰기의 표시도 검사한다. 검색·복사·가입·게시글 등 기존 시나리오는 변경된 문구에 맞춰 다시 실행한다.
