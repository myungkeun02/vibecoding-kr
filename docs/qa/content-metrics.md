# 공개 집계와 화면 문구 정리

2026-09-16. 대체 경험 버튼 응답과 도구 요금을 곱한 추정 합계를 제거하고 공개 콘텐츠 수로 교체했다.

- `guides`: 활성 제작 가이드 수. 각 상세 페이지로 연결된 도구 목록과 일치한다.
- `services`: 운영자가 공개했으며 등록자의 계정이 활성인 SaaS 수. 검토 중·보완 요청·공개 중지 상태는 제외한다.
- `builds`: 공개된 제작 후기·작품 게시글 수. 질문·댓글·숨김·삭제된 글은 제외한다.
- 도구별 후기 수와 ‘후기 많은 순’도 같은 공개 builds 글로 계산한다. 도구 상세의 후기 목록도 builds로 제한한다.
- 기존 대체 경험 응답은 보존하되 사람 수나 절약액으로 바꾸지 않는다. 공개 합계 API에서 `monthly`, `excluded`를 제거했다.
- 홈·현황·커뮤니티·계정·SaaS 등록 문구를 기능 중심으로 정리했다. ‘함께 만든 변화’ → ‘등록 현황’, ‘함께 찾은 SaaS’ → ‘SaaS 모음’, ‘로그인하고 이어서 만들어요’ → ‘로그인’.

## 검증 범위

PostgreSQL에서 공개 상태·게시판·연결 도구·삭제 여부가 집계에 반영되는지 검사한다. 브라우저에서는 글 작성→후기 수 증가→숨김→감소, 숫자의 목록 링크, 대체 경험 표시 후 콘텐츠 합계 불변, 라이트·다크 모드 360·390·768·1440px 화면을 확인한다. 기존 회원·SaaS 등록·검색 기능도 회귀 검사한다.

최종 로컬 결과: 타입 검사 오류 0·경고 0(기존 클립보드 호환 API 안내 1개), 단위 검사 27개, 브라우저 시나리오 27개 통과. 삭제한 메뉴명·가격 테이프를 참조하던 기존 브라우저 검사를 새 화면에 맞게 고친 뒤 전체 시나리오를 다시 확인했다. 121개 공개 가이드와 빌드 검증도 통과했다. 아래 캡처의 회원·글은 격리된 PostgreSQL의 시험 데이터다.

## 운영 도메인 확인

운영 DB를 직접 조회한 공개 가이드 121개·SaaS 0개·제작 후기 0건이 실제 화면 및 API와 일치했다. 운영 콘텐츠는 추가·변경하지 않고 확인했다. 홈·현황·SaaS·커뮤니티·로그인·회원가입을 라이트·다크 모드와 360·390·768·1440px에서 확인했고 가로 넘침이나 브라우저 오류가 없었다. 수치는 각 콘텐츠 목록에 연결되며 기존 금액 합계는 표시되지 않는다.
