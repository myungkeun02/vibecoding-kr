# SaaS 공동 목록과 제작 가이드 통합 검증

2026-09-16. 초기 121개와 회원 등록 SaaS를 동일한 저장·검색·편집 흐름으로 합쳤다. 기존 URL을 보존하며 `/services`는 홈 목록으로 이동한다. 가이드 유무를 필터로 구분하고 모바일 목록 상단에서도 등록할 수 있다.

## 검증한 동작

- 회원이 초기 Trello의 이름·소개·가이드·이미지 수정 제안을 제출한다. 승인 전 원본과 기존 이미지는 공개 유지하고 새 이미지는 제안자·운영자만 볼 수 있다.
- 운영자가 수정 전·후를 비교해 반영하면 기존 URL·통합 검색에 즉시 나타난다. 내 활동에서도 반영 상태를 확인한다.
- 다른 회원이 등록한 공개 SaaS도 수정할 수 있다. 비공개 등록의 편집·타인 삭제·타인 제안 열람·회원의 승인 요청은 차단한다.
- 같은 revision에서 시작한 두 제안 중 하나가 반영되면 나머지 승인 요청은 409다. 검토 중 제안은 작성자가 취소할 수 있다. 변경이 없는 제출과 이미 처리한 제안의 재승인도 거절한다.
- JavaScript를 끈 브라우저에서 다른 회원의 SaaS에 가이드를 추가한다. 승인 전 가이드 수가 늘지 않고, 승인 후 가이드 필터와 집계에 반영된다.
- 새 SaaS에 제작 후기를 연결하고 목록의 후기 수와 상세에 표시한다.
- 초기 가이드의 승인된 수정과 제안 기록이 실제 서버 재시작·seed·PostgreSQL 백업 복원 뒤에도 유지된다.

단위 검사 28개·전체 브라우저 시나리오 30개 통과. 타입 검사 오류·경고 0개(기존 클립보드 호환 API 안내 1개). 카탈로그·빌드 검증, 재시작/복원, 운영 모드 HTTPS/메일 정책 검사 통과. 이미지 비교 화면을 경로 텍스트 대신 이미지로 표시하도록 다듬은 뒤 공동 편집 시나리오 3개도 다시 통과했다. 초기 121개 모두 공동 편집기의 입력 기준을 통과하는지도 확인했다.

검사는 격리된 PostgreSQL에서 수행했다. 운영 변경 전 DB 백업을 별도로 확보했다. 운영 계정에 권한을 임의 부여하거나 기존 공개 내용을 시험 값으로 바꾸지 않는다.

## 운영 도메인 확인

`https://vibepan.com` 배포 후 SaaS 121개·가이드 121개·제작 후기 0건이 DB와 공개 API·화면에서 일치한다. 이전 121개 URL, 통합 검색, 가이드 있음/없음, 분야별 목록, 로그인으로 이어지는 등록·수정 진입을 확인했다. 라이트·다크 모드와 360·390·768·1440px에서 가로 넘침과 브라우저 예외가 없다. 운영 콘텐츠를 시험 값으로 바꾸지 않았다.

운영 DB의 제약 위반은 없으며 운영자 계정 수는 0이다. 승인할 계정은 사용자의 이메일 지정을 기다리며 임의로 승격하지 않았다.

CI에서는 승인 요청이 끝나기 전에 방문자 화면을 새로 고치는 검사 순서 문제를 발견했다. 같은 관리자 URL을 기다리던 검사를 실제 승인 응답이 끝날 때까지 기다리도록 수정했다. 서비스 동작 코드는 바뀌지 않았다.
