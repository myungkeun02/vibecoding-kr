# SaaS 등록 기능 검증

2026-09-16. 실제 PostgreSQL 격리 스키마와 운영 빌드에서 검증했다. 화면 캡처의 서비스·계정·이미지는 시험용 데이터다.

## 확인 범위

- 회원의 등록 폼 입력, 5MB 이하 이미지 첨부와 미리보기, 내 활동 등록 상태.
- 운영자 화면의 소개·이미지 검토 및 공개, 공개 서비스 검색과 분야 필터.
- 검토 전 상세·이미지·사이트맵 비공개, 승인 후 공개, 수정 후 재검토, 운영자 공개 중지, 소유자 삭제.
- 로그인·출처·CSRF, 소유권, 이미지 소유권, 운영자 권한, URL 검증, 기존 카탈로그 중복, 정규화 주소 중복과 동시 등록.
- 동시 수정 및 오래된 검토 화면의 변경 거부, 스크립트 입력의 브라우저 비실행.
- 보완 안내, 스크립트를 끈 브라우저의 일반 폼 제출, 계정 이용 제한 및 탈퇴 후 비공개/삭제.
- 360·390·768·1440px 입력 화면의 가로 넘침 확인. 실제 휴대폰 하드웨어 검사는 포함하지 않는다.
- 실제 프로세스 재시작·PostgreSQL 백업/복원 뒤 등록한 SaaS와 세션 유지.

초기 검사에서 수정 폼의 textarea 레이블 식별, 한국어 홈페이지 주소의 중복, 스크립트를 끈 화면에서 하단 메뉴 겹침과 부드러운 스크롤 중 버튼 클릭을 수정했다. HTML 속성에 안전하게 인코딩된 문구를 오탐하던 XSS 검사는 실제 브라우저의 스크립트 요소·실행 여부를 확인하도록 바꿨다.

## 실제 도메인 확인

`https://vibepan.com`에 배포한 뒤 모바일 브라우저에서 회원 등록 → SaaS 작성·이미지 첨부 → 검토 중 비공개 → 내 활동 → 수정 → 삭제를 확인했다. 목록은 라이트·다크 모드와 360·390·768·1440px에서 가로 넘침이 없었다. 시험 계정·서비스·첨부 파일은 정리했고 공개 승인을 하지 않았다. 공개 승인 전체 흐름은 격리된 PostgreSQL에서 확인했으며, 운영 환경의 검토 담당 계정은 사용자 지정 대기 중이다.
