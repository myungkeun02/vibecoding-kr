# 서비스 마스코트 적용 검증

2026-09-16. 사용자가 선택한 주황 로봇 이미지를 공통 안내·빈 상태·오류 화면으로 확장했다. 기존 원본의 색·표정·형태를 유지했고, 고해상도 표시용 WebP 한 파일만 추가했다.

## 적용

로그인, 이메일/소셜 가입, 비밀번호 재설정, 수신 거부, 내 활동, 대체 현황, 도구 제안의 머리말을 공통 `BrandIntro`로 구성했다. 검색·커뮤니티·알림·저장 도구·공개 프로필·도구별 제작 이야기의 빈 상태는 `EmptyState`를 사용한다. 홈의 제작 범위 안내, 업데이트 구독과 404 화면에도 같은 이미지를 표시한다.

이미지는 장식으로 처리해 접근성 이름을 중복하지 않으며 고정 크기로 배치 공간을 확보했다. 모바일에서는 머리말 56px, 간단한 안내 48px, 독립된 빈 상태 88px다. 한국어 제목과 안내가 어절 단위로 줄바꿈되도록 했다.

## 검사 결과

- 타입 검사 오류 0·경고 0. 기존 클립보드 호환 API의 안내 1개는 남아 있다.
- 운영 빌드와 기존 브라우저 시나리오 23개 통과.
- 마지막 줄바꿈 조정 후 다시 빌드한 운영 번들을 사용해 로그인·회원가입·빈 검색·빈 커뮤니티·도구/분야 404·대체 현황을 360·390·1440px 및 밝은/어두운 테마에서 확인했다. 가로 넘침과 브라우저 예외가 없었다.
- 캐릭터 파일의 로드 및 장식용 접근성 속성, 데스크톱 홈 안내를 확인했다.
- 격리된 테스트 계정의 가입·로그인·작성·저장·프로필 흐름은 기존 브라우저 검사로 확인했다. 실제 휴대폰 하드웨어 검사는 포함하지 않는다.

## 운영 확인

공개 소스 `d242c153ebf19f236253c617c9559221fa305fc5`, Railway 배포 `25c284fc-febf-4eb2-8835-3f00a19804f6`가 성공했다. 실제 HTTPS 주소에서 로그인·회원가입·빈 검색·빈 커뮤니티·도구/분야 404·대체 현황을 다크/라이트 및 360/390px로 검사했고, 데스크톱 홈 안내·서비스 로고 메타데이터·새 WebP 파일 응답도 확인했다. 브라우저 예외가 없었다. 공개 DNS 조회와 정상 TLS 검증을 사용했으며 [운영 결과](mascot-production-results.json)에 기록했다.
