## 시각 검토와 증거

## 남은 제약과 상태 구분

주요 로컬 사용 흐름에 남은 **FAIL은 없다**. 실제 외부 키·공급자 계정이 필요한 연동과 실제 인터넷 운영 배포는 완료로 보고하지 않는다. Docker 엔진 실행과 영속 볼륨의 실제 호스팅 확인이 필요하다. 별도 공개 도메인 없이 기존 로컬 미리보기를 인터넷 배포라고 부르지 않는다.

도구 가격 대부분은 확인 필요로 남겨 두었고, 공식 페이지 확인 실패 후보 6개는 정식 카탈로그에서 제외했다. 121개 제작 프롬프트의 결과물을 실제로 만드는 작업은 **NOT_RUN**이며 화면에도 편집 검토로 명시한다. 익명 쿠키 삭제에 의한 동일인 재인증을 완벽히 막지는 못한다. SQLite는 단일 프로세스 운영 기준이며 부하·침투·법적 적합성의 인증을 주장하지 않는다. 정책의 운영 주체·연락처를 실제 배포 전에 확정해야 한다.

## 2026-09-10 로컬 소셜 로그인 연결

GitHub·Google 자격은 Git에서 제외된 비공개 환경파일에만 저장했다. 등록된 4321 포트와 `/api/auth/callback/:provider` 경로에 맞췄으며, 이전 콜백 경로도 같은 인증 처리를 사용한다. 로그인 요청의 공급자와 콜백의 공급자가 다르면 인증을 거부한다.

타입 검사 오류 0·경고 0, 단위 검사 21개, 서버 빌드, 관련 브라우저 시나리오 E11이 통과했다. 추가한 단위 검사는 두 공급자의 인증 요청과 토큰 교환에 같은 콜백 주소가 쓰이는지, 신규 가입 안내 전 사용자 생성이 없는지, 만료·변조·누락·다른 공급자·다른 state·동의 거부 요청을 외부 통신 전에 차단하는지 확인한다.

실제 로컬 로그인 화면의 두 버튼, 8095에서 4321로 이어지는 임시 로컬 이동, 390px 화면과 브라우저 HTML의 비밀키 미포함을 확인했다. 외부 로그인 화면은 GitHub와 Google 모두 표시됐으며 콜백 주소 오류는 나타나지 않았다. **실제 계정의 인증·동의, 토큰 발급, 가입 완료는 미검증**이다. 외부 서비스 로그인 화면 표시와 모의 응답 검사만으로 전체 로그인 성공을 주장하지 않는다.
