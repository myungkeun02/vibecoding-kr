# 사용자 SaaS 등록

회원은 `/services/new`에서 자신이 만든 SaaS 또는 추천 서비스를 등록한다. 이름·공식 주소·분야·요금 방식·한 줄 소개·상세 소개를 입력하고 PNG/JPEG/WebP 이미지 한 장을 선택적으로 첨부한다. 이미지 처리는 기존 5MB 제한과 서버 WebP 변환을 재사용한다.

## 공개 흐름

1. 로그인 후 등록 → `pending`(검토 중). 등록자와 운영자만 소개와 첨부 이미지를 볼 수 있다.
2. 운영자는 `/admin#services`에서 내용·공식 주소·이미지를 검토하고 공개하거나 보완을 요청한다.
3. 공개한 서비스는 `/services`의 검색·분야별 목록과 `/services/:id`에 바로 표시된다. 별도 소스 수정이나 재배포가 필요하지 않다.
4. 등록자는 `/me#my-services`에서 상태와 운영자 안내를 확인한다. 수정하면 다시 검토 중으로 바뀌며, 재승인 전에는 공개 목록에서 빠진다.
5. 등록자 삭제 또는 계정 탈퇴 시 서비스가 삭제된다. 운영자 공개 중지나 등록자 계정 이용 제한 시 목록·상세·이미지·사이트맵에서 공개되지 않는다.

운영자 권한은 기존 운영 절차(`pnpm admin <가입 이메일>`)로 지정하며, 첫 가입자에게 자동 부여하지 않는다. 운영자의 공개·보완 요청·공개 중지와 등록자의 변경은 운영 기록에 남는다.

## 데이터와 검증

- PostgreSQL `002-services.sql`은 기존 테이블을 바꾸지 않고 `services` 테이블·색인만 추가한다.
- 기존 편집 검토 카탈로그는 JSON을 유지한다. 사용자 등록 SaaS는 DB에서 제공하며, 제작 가능성 평가나 제작 요청문을 임의로 생성하지 않는다.
- 등록 주소는 공개 HTTP(S) 주소만 받는다. 사용자 정보가 포함된 URL, IP 주소와 로컬 주소를 거부하며, 서버에서 외부 URL을 요청하지 않는다.
- 추적 쿼리·프래그먼트·www·끝 슬래시·`intl/언어` 홈페이지 변형을 정규화해 중복을 확인하고, DB 고유 제약으로 동시 등록도 막는다. 다른 제품 경로는 별개로 취급한다.
- 첨부 이미지는 등록자 소유 업로드인지 확인한다. 검토 전 이미지는 등록자와 해당 서비스의 운영자 검토에만 공개한다.
- 본문은 HTML/Markdown을 실행하지 않는 일반 텍스트로 렌더링한다. 외부 서비스 링크는 `nofollow ugc noopener noreferrer`를 사용한다.
- 등록자만 수정·삭제할 수 있고, 운영자만 검토 상태를 바꿀 수 있다. revision과 행 잠금으로 오래된 화면이나 동시 변경의 덮어쓰기를 거부한다.
- 사용자당 등록·수정은 하루 15회이며 기존 출처·CSRF·전체 요청 제한도 적용한다.

## 진입점

홈의 ‘사용자 등록 SaaS’ 탭, 데스크톱 ‘SaaS 모음’, 모바일 도구 목록 끝의 ‘SaaS 등록하기’, 내 활동, 하단 메뉴와 기존 정보 수정 제안 화면에서 연결된다. 비회원의 등록 요청은 로그인 후 원래 화면으로 돌아온다.
