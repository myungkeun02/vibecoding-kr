# 최신 제품 기획 · 2026-09-08

## 목표와 범위

기존 이름 **바이브코딩가능?**를 유지한다. 한국의 개인 빌더와 소규모 팀이 자신이 쓰는 기능에 한정한 대체 가능성을 판단하고, 프롬프트를 실행한 뒤 실제 결과를 공유한다. 사용량이나 절약액을 가공해 흥행을 연출하지 않는다. 결제·광고·수익 배분은 범위 밖이다.

## 사용 흐름

홈 검색 → 판정·유형·가격·카테고리로 좁히기 → 도구 상세에서 사용 사례·손실·가격 근거 확인 → Claude Code/Codex/Cursor 지침과 프롬프트 복사 → 직접 제작 → 대체 인증 또는 관련 제작 후기 게시.

회원은 이메일·비밀번호와 서버 세션으로 가입한다. 이메일 확인과 비밀번호 재설정은 30분 유효 토큰으로 진행한다. 이메일 확인 전에도 기본 기능을 사용할 수 있지만 확인 완료라고 표시하지 않는다. Google/GitHub는 기존 기획의 제공자를 유지하고 준비된 경우에만 켠다. 새 소셜 계정도 약관 동의 후 생성한다. 이메일 문자열만 같다고 다른 계정을 자동 연결하지 않는다.

## 판정과 가격

YES는 명시한 작은 범위의 핵심 기능 대체, KINDA는 중요한 협업·연동·품질 손실, NOT REALLY는 핵심 엔진·인프라·네트워크를 복제하기 어려운 경우다. no 도구에도 제한적인 보조 도구 프롬프트를 제공한다.

2026-09-16 사용자 요청에 따라 대체 응답 수와 요금을 곱한 금액 합계를 제거했다. 공개 현황은 실제 열어볼 수 있는 가이드·SaaS·제작 후기 개수만 표시하고, 각 수치를 해당 목록에 연결한다. 제작 후기는 공개 builds 게시글의 수이며 제작 성공이나 절약을 검증한 수치가 아니다. 도구 정렬도 후기 수를 사용한다. 대체 경험 버튼 응답은 별도 보존하며 계정·쿠키별 중복 방지와 로그인 병합을 유지한다.

## 디자인과 접근성

차분한 다크·라이트 모드와 주황색 강조색, 얇은 선과 8px 모서리를 사용한다. 판정은 색과 텍스트를 함께 표시한다. Space Grotesk·JetBrains Mono·Pretendard를 자체 호스팅한다. 검색 가능한 행 중심 디렉터리, 정적인 콘텐츠 수·절제된 등장 효과, 키보드 포커스·폼 레이블·reduced-motion을 제공한다. 360/390/768/1440px를 확인한다.

## 운영과 공개

초기 자료는 JSON에서 가져오고 SaaS의 공개 기본 정보·제작 가이드는 PostgreSQL에서 관리한다. 누구나 가입 후 새 항목을 등록하거나 기존 항목에 수정 제안을 할 수 있다. 운영자가 검토해 반영하며 검토 중에도 기존 공개 내용은 유지한다. 가이드가 없는 항목에 다른 회원이 가이드를 추가할 수 있다. 인증·메일·스토리지 공급자의 실제 연결 확인은 내부 로직 QA와 분리한다. 운영 주체·연락처와 HTTPS·영속 볼륨을 실제 운영 배포 때 설정한다.
