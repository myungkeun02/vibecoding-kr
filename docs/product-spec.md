# 최신 제품 기획 · 2026-09-08

## 목표와 범위

기존 이름 **바이브코딩가능?**를 유지한다. 한국의 개인 빌더와 소규모 팀이 자신이 쓰는 기능에 한정한 대체 가능성을 판단하고, 프롬프트를 실행한 뒤 실제 결과를 공유한다. 사용량이나 절약액을 가공해 흥행을 연출하지 않는다. 결제·광고·수익 배분은 범위 밖이다.

## 사용 흐름

홈 검색 → 판정·유형·가격·카테고리로 좁히기 → 도구 상세에서 사용 사례·손실·가격 근거 확인 → Claude Code/Codex/Cursor 지침과 프롬프트 복사 → 직접 제작 → 대체 인증 또는 관련 제작 후기 게시.

회원은 이메일·비밀번호와 서버 세션으로 가입한다. 이메일 확인과 비밀번호 재설정은 30분 유효 토큰으로 진행한다. 이메일 확인 전에도 기본 기능을 사용할 수 있지만 확인 완료라고 표시하지 않는다. Google/GitHub는 기존 기획의 제공자를 유지하고 준비된 경우에만 켠다. 새 소셜 계정도 약관 동의 후 생성한다. 이메일 문자열만 같다고 다른 계정을 자동 연결하지 않는다.

## 판정과 가격

YES는 명시한 작은 범위의 핵심 기능 대체, KINDA는 중요한 협업·연동·품질 손실, NOT REALLY는 핵심 엔진·인프라·네트워크를 복제하기 어려운 경우다. no 도구에도 제한적인 보조 도구 프롬프트를 제공한다.

월 합계는 `유효 인증 수 × 확인된 기준 플랜 원화 월 환산액`이다. 실제 절약액, 회사 매출 감소, 운영비를 뺀 순이익으로 표현하지 않는다. 무료는 0, 미확인·일회성·사용량·견적형은 null로 분리한다. 회원과 비회원 모두 인증할 수 있고 로그인 시 중복을 병합한다. 익명 쿠키를 지우거나 다른 브라우저를 쓰는 동일인을 완벽히 식별하지는 못한다.

## 디자인과 접근성

CRT 계열 다크와 종이 계열 라이트, 형광 초록 강조색을 사용한다. 판정은 색과 텍스트를 함께 표시한다. Space Grotesk·JetBrains Mono·Pretendard를 자체 호스팅한다. 검색 가능한 행 중심 디렉터리, 숫자 롤링·가격 테이프·절제된 등장 효과, 키보드 포커스·폼 레이블·reduced-motion을 제공한다. 360/390/768/1440px를 확인한다.

## 운영과 공개

JSON은 Git으로 검토·빌드·배포하고 런타임 데이터는 PostgreSQL에 저장한다. 제안의 채택과 공개 배포는 별도 상태다. 인증·메일·스토리지 공급자의 실제 연결 확인은 내부 로직 QA와 분리한다. 운영 주체·연락처와 HTTPS·영속 볼륨을 실제 운영 배포 때 설정한다.
